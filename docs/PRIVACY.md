# 配置与隐私说明

## Git 仓库

- `project.config.json`、`project.private.config.json`、`miniprogram/config.local.js` 仅留在本地。
- 对外仅提供 `project.config.example.json` 和 `miniprogram/config.example.js`，所有标识均为占位符。
- 源码和文档不写真实 AppID、环境 ID、云存储桶地址、用户记录、轨迹或访问凭据。
- README 中的小程序码是主动公开的宣传入口，扫描可访问对应小程序；请勿将私人后台、调试二维码当成宣传图片上传。
- 提交前运行 `node scripts/check-publication.js`，它检查暂存的文件路径、文本标识和本地配置值。检查不替代人工核对，尤其是截图、压缩包或图片元数据。

## 运行时数据

小程序会申请定位权限。轨迹与待同步进度保存在设备本地，云端保存档案、地图标记和里程统计。位置标记、宠物展示资料与榜单具有社交展示用途，部署者需告知用户具体用途并配置对应权限。详细恢复行为见统计文档。

Git 忽略规则只影响仓库上传，不会从最终小程序代码包中隐藏运行配置；客户端配置不能存放 AppSecret、服务端私钥等凭据。这些应保存在受控的服务端环境中。

如果未来发生误提交，立即停止继续传播，撤销泄露的凭据并清理历史；仅在最新版本删除文件不能清除 Git 历史中的内容。报告问题时不要在公开 Issue 中贴出真实凭据或用户数据。
